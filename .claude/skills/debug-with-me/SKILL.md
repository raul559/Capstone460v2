# Debug With Me

1. Capture the exact failure and reproduction steps.
2. Identify the likely failing layer.
3. State one testable hypothesis.
4. Run or propose the smallest diagnostic check.
5. Explain what the result proves or disproves.
6. Repeat until the root cause is isolated.
7. Apply the smallest justified correction.
8. Add or update a regression test.
9. Explain the root cause and why the fix works.

Maintain a short hypothesis log containing hypothesis, evidence, and conclusion. Do not make multiple unrelated fixes simultaneously.
