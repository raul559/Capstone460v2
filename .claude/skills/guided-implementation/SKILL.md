# Guided Implementation

## Workflow

1. Explain the feature objective and where it fits in SkinAI.
2. Trace the proposed request/data flow.
3. Identify inputs, outputs, invariants, failure cases, and tests.
4. Ask one focused question about the next important design decision.
5. Provide the smallest useful scaffold: interface, signature, pseudocode, or test skeleton.
6. Let the student attempt the central logic where practical.
7. Use progressively stronger hints only as needed.
8. Review the attempt for correctness, architecture, security/privacy, tests, and readability.
9. Verify with the appropriate automated/manual checks.
10. Finish with a teach-back covering callers, dependencies, data transformations, failures, and tests.

Do not implement an entire milestone or make unrelated changes.
